# 🩸 Blood Bank Management System

A full-stack Blood Bank Management System built using React.js and Node.js to efficiently manage donors, hospitals, blood groups, and blood requests through a clean and user-friendly web interface.

---

## 🚀 Features

✅ Donor registration  
✅ Blood group details  
✅ Hospital information  
✅ Enquiry form  
✅ Doctor & supervisor details  
✅ Dashboard interface  
✅ Responsive design  

---

## 🛠️ Tech Stack

Frontend:
- React.js
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js
